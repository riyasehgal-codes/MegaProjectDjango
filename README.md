# Tweetbar ♡

A small Django-based social diary built to practice full-stack web development.

Users can register, log in, create tweets, upload photos, and manage their posts — all wrapped in a soft, diary-inspired UI.

## Tech Stack

- Python
- Django
- HTML/CSS
- Bootstrap
- PostgreSQL
- Neon
- Vercel

## Current Status

> **Practice Project — Work in Progress**

Tweetbar was primarily built as a **Django practice project**, so many features are currently incomplete or not fully functional.

The main goal was to learn and experiment with:

- Django CRUD
- Authentication
- Forms & Models
- User permissions
- File uploads
- PostgreSQL
- Deployment with Vercel

More features and improvements may come later.
